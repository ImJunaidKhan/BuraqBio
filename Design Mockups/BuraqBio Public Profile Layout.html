Builder notes

Everything you need to rebuild p.html by hand. The page is one centered column — no header, no nav. It reads the username from the URL, loads that user from Firebase, and renders the blocks below.

1Layout structure

body.dark ← Deep Start background + purple glows └─ main.profile ← max-width: 480px, centered, text-align: center ├─ .avatar ← 112px circle, photo URL from the profile doc ├─ h2 ← display name ├─ .handle ← small pill: buraqbio.link/u/<username> ├─ p.intro ← short intro, max 120 characters ├─ .links ← one .profile-link per link, in saved order │ └─ a.profile-link │ ├─ .ic ← 38px icon tile │ ├─ .lbl ← link title │ └─ .chev ← › arrow, hints it opens something └─ .powered ← tiny wing + "Powered by BuraqBio", always last If the username does not exist → swap main.profile for .nf-card (wing, message, Back to homepage button). Nothing else changes.

4Notes before you code it

  • Read the username first. profile.js takes the name from the URL (/u/sweetcrumb), looks it up in the Realtime Database, and fills the skeleton. No match → show the .nf-card, hide main.profile.
  • Count the click before you send them off. On tap, increment that link's counter in the database, then open the URL. It is the same counter the dashboard reads.
  • Links open in a new tab (target="_blank" rel="noopener") so the profile page stays open behind them.
  • The theme is one body class. The dashboard picker saves a theme name on the profile; p.html maps it to theme-teal, theme-rose and so on. Buttons and glass never change, only the background does.
  • No login, no header. This page is public and shareable — keep it to the column and the footer. The "Powered by" line is your free advertising on every page.
