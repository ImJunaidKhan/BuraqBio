Logo — a text wordmark

No icon, no symbol. The logo is the name itself, set in Segoe UI: Buraq in Semibold, Bio in Light. The weight contrast is the whole trick — it is what made the Windows 8 Start screen wordmarks feel premium. Works at any size, in one colour, with zero assets to maintain.

Does .link need to be there?

Both are approved — they answer different jobs. BuraqBio.link is the marketing lockup: it tells a stranger the exact address to type, which matters when the logo is printed on a poster, a shop card or an Instagram caption. BuraqBio is the product lockup: cleaner inside the app, where the user is already there.

The .link is always set smaller (about half size), in Metro Purple — Light Violet on dark backgrounds — aligned to the baseline. It is a suffix, not part of the name. Never write it the same size or weight as “Bio”.

Rules

  • ✓Keep clear space around the wordmark equal to the height of the “B”.
  • ✓Minimum size: 20px tall on screen — below that, use the favicon mark instead.
  • ✓In plain text and URLs, always write it as buraqbio.link in lowercase.
  • ✕Don’t add a gradient, shadow, outline or a symbol next to it.
  • ✕Don’t set “Buraq” in Light or “Bio” in Bold — the contrast is the logo.
  • ✕Don’t recolour it anything except ink, white, or Metro Purple on white.

Build it in HTML, not an image: <span class="wm"><b>Buraq</b><span class="bio">Bio</span><span class="tld">.link</span></span> with b{font-weight:600} and .bio{font-weight:300}. It stays sharp at every size and weighs nothing.

Colour system — nine colours plus one accent

Deliberately small and modern: ten colours total. One purple family does the brand work — Primary: Metro Purple, Secondary: Light Violet, with Deep Start as the dark backdrop — while Ink, Muted, Paper and White handle text and surfaces. Accent: Metro Gold is the single disciplined accent, kept for the small moments that must stand out. Two of the nine are borrowed for single jobs only: WhatsApp Green appears only on WhatsApp buy buttons, and Error Red only on form errors. Everything else you will see — hover states, tints, the glass — is one of these ten at a different strength, never a new hue. Tap any swatch to copy its hex.

How the purple is used

Metro Purple is a working colour, not a decoration. It marks the primary button on every screen and the logo’s .link suffix family. Deep Start is only for large background areas — the hero, the auth screens, the public profile backdrop — never for body text on white. The small moments of emphasis — a price, a badge, a focus ring, an active state — belong to the gold accent instead. If everything is purple, nothing is. Keep most of the UI ink-on-white and let purple appear at the moments of action.

Pairing rules

  • ✓Body text is always Ink #1B1030 on Paper or White, or White on Deep Start — never purple body text.
  • ✓Links are Metro Purple on light backgrounds and Light Violet on dark ones — the same purple family, never a separate link colour.
  • ✓Hover and soft-fill states are shades and tints of Metro Purple — the same colour at a different strength, not new colours.
  • ✓Metro Gold is used sparingly — about 5% of any screen — for prices, badges, focus rings, active states and small highlights. Nothing bigger.
  • ✓Gold badges and chips always set Deep Start #1C0B45 text on the gold fill — that pairing is what keeps gold readable.
  • ✕Never gold body text, and never a gold main button. Main buttons stay Metro Purple.
  • ✓WhatsApp Green #25D366 appears on WhatsApp buy buttons and nowhere else. It is a borrowed brand colour, not part of the palette.
  • ✓Error Red #D92B3A is for form errors only — never buttons, badges or decoration.
  • ✕Never add a colour outside these ten. If a screen feels flat, fix it with spacing and type, not a new hue.

Typography — Segoe UI

The Windows 8 typeface, and it is already on every Windows machine your users own — no webfont download, no FOUT, instant load. Its Light weight at large sizes is the signature Metro look. On Mac and phones the stack falls back to the system font, which keeps the same clean feel.

The font stack

font-family: "Segoe UI", "Segoe UI Variable Text", system-ui, -apple-system, Arial, sans-serif;

Rules: sentence case everywhere (Windows 8 style — no ALL-CAPS headings), tight tracking only on sizes above 24px, and never use Light below 24px — it disappears on cheap phone screens. Numbers in prices and stats use Semibold so they scan fast.

The glass system

macOS-style frosted glass, used the way Apple uses it: for surfaces that float over content — the auth card, the public profile, sticky nav, modals. Never for plain content pages like the dashboard lists; glass everywhere stops meaning anything. It only works over colour, which is exactly what the Deep Start purple backdrop provides.

Glass on dark (primary)

White at 13–16% opacity over the purple backdrop, 20px blur, a bright 1px top edge. This is the auth card and the public profile.

Glass on light

White at 60% opacity over a light photo or pale backdrop. Use for sticky headers and floating action bars in the dashboard.

The recipe

backdrop-filter: blur(18px) saturate(160%) · border: 1px solid rgba(255,255,255,.35) · shadow: soft, dark, wide. Saturate is the secret — it keeps the purple rich through the frost instead of going grey.

Blurbackdrop-filter: blur(18px) saturate(160%) — always pair blur with saturate, and add the -webkit- prefix for Safari.
Fill — darkbackground: rgba(255,255,255,0.13) on cards over Deep Start / Metro backdrops.
Fill — lightbackground: rgba(255,255,255,0.62) on cards over photos or pale backdrops.
Borderborder: 1px solid rgba(255,255,255,0.35) plus inset 0 1px 0 rgba(255,255,255,.35) for the lit top edge.
Radius18–22px on glass cards. Glass with sharp corners reads as Windows 8 tile; rounded reads as macOS. You want macOS here.
FallbackWhere backdrop-filter is unsupported, the same card must still read well as a translucent panel — never put essential text directly on the backdrop without the card behind it.

Dashboard, in one line of guidance

The dashboard is not glass — it is flat white cards on the Paper background, Metro buttons, Ink text. Glass is saved for the two moments a visitor sees: signing in, and your public page. That contrast is what makes the public page feel premium when a customer lands on it.

Copy-paste tokens

Drop these into your main stylesheet on day one and every page inherits the brand. For Bootstrap, the same hex values map to --bs-primary, --bs-link-color and --bs-body-color — or use the Bootstrap data-bs-theme overrides in your own CSS file loaded after Bootstrap.
