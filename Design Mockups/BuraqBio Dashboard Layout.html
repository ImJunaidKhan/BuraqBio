Builder notes: recreate this dashboard

Same global style.css as the other pages — this page only adds the dashboard section at the bottom of that file. It is the one light page in the set: no body.dark, no glass. White cards on Paper, soft --line borders.

1 · Layout structure, top to bottom

Build it in this order. Each row is one block of dashboard.html with the tag and class names used on this page.

1
Top bar<header class="topbar">

Sticky white bar with a soft bottom border. Logo left (horizontal wing lockup, dark version — it sits on white here). Right side: the public URL chip, View page button, Logout. Under 640px the actions wrap onto their own row.

2
URL chip.url-chip

Pill in --metro-soft with a green live dot, the user's URL as text, and a small white Copy button inside the pill. Copy uses navigator.clipboard.writeText() with the URL you build from their username.

3
Page container.wrap

Same container idea as the homepage but narrower: max-width: 920px. A dashboard is a working page, not a wide showcase — one column of cards reads better and is less CSS.

4
Profile card.card .profile-grid

White card, 1px --line border, 14px radius. Inside: a 2-column grid — avatar preview (round, 110px) left, fields right. Photo URL, display name, intro textarea with a live character count, then the theme swatches. Stacks to one column under 640px.

5
Theme swatches.swatches .swatch

Round buttons, 38px. The selected one gets the gold ring — gold is allowed here because a selected state works like a focus ring. Store the picked colour name on the user's profile; the public page reads it and sets its button colour.

6
Add-link form.add-form

A tinted inner panel (Paper background) with a 3-column grid: title field, URL field, Add button aligned to the bottom of the inputs. One column under 760px. The same form doubles as the edit form — Edit fills it and the button switches to "Save changes".

7
Link rows.link-row

One bordered row per link, flex with a gap: drag dots, title + URL (URL in muted, cut with ellipsis), gold click badge, then four icon buttons — up, down, edit, delete. First row's up button and last row's down button are disabled. On mobile the row wraps: badge and buttons drop to a second line.

8
Click badge.click-badge

Gold-tinted pill: pale gold fill (#FFF4D6), 1px gold border, dark gold text, small chart icon + count. This is the one place gold appears in every row — it is a badge, which the brand allows. In your real build the number comes from the counter you increment on the public page.

2 · CSS to add — the dashboard section of style.css

Paste below your global block. Only the new pieces: cards, rows, chip, swatches. Buttons, inputs and labels are already in your global CSS.

Dashboard section
/* 6. Dashboard (light page — no body.dark) */
.wrap{max-width:920px;margin:0 auto;padding:0 20px}
.card{background:var(--white);border:1px solid var(--line);
  border-radius:14px;padding:24px;margin-top:20px}
.topbar{position:sticky;top:0;background:var(--white);
  border-bottom:1px solid var(--line)}
.url-chip{display:inline-flex;align-items:center;gap:8px;
  background:var(--metro-soft);border:1px solid var(--line);
  border-radius:999px;padding:6px 6px 6px 14px;font-weight:600}
.profile-grid{display:grid;grid-template-columns:150px 1fr;gap:22px}
.avatar-preview{width:110px;height:110px;border-radius:50%;
  object-fit:cover;border:3px solid var(--metro-soft)}
.swatch{width:38px;height:38px;border-radius:50%;
  border:2px solid var(--line);cursor:pointer}
.swatch[aria-pressed="true"]{border-color:var(--accent);
  box-shadow:0 0 0 3px rgba(255,185,0,.4)}  /* gold ring = selected */
.add-form{display:grid;grid-template-columns:1fr 1.4fr auto;
  gap:10px;align-items:end;background:var(--paper);
  border:1px solid var(--line);border-radius:12px;padding:14px}
.link-row{display:flex;align-items:center;gap:12px;
  border:1px solid var(--line);border-radius:12px;padding:12px 14px}
.click-badge{background:#FFF4D6;border:1px solid var(--accent);
  color:#7A5200;font-weight:700;font-size:12.5px;
  border-radius:999px;padding:4px 11px}       /* gold = badges */
.icon-btn{width:32px;height:32px;border:0;border-radius:8px;
  background:none;color:var(--muted)}
.icon-btn:hover{background:var(--metro-soft);color:var(--metro)}
@media (max-width:760px){ .add-form{grid-template-columns:1fr} }
@media (max-width:640px){
  .profile-grid{grid-template-columns:1fr}
  .link-row{flex-wrap:wrap}
}

3 · HTML skeleton — the dashboard in 20 lines

Start dashboard.html from this, then fill each block using the map above. The link rows are repeated by your JavaScript from the database — write one row well, then loop it.

dashboard.html skeleton
<header class="topbar">
  logo (dark) · .url-chip with Copy · View page · Logout
</header>
<main class="wrap">
  <h1>Dashboard</h1>
  <section class="card">            <!-- Profile -->
    <div class="profile-grid">
      avatar preview | photo URL · name · intro · swatches
    </div>
    mini preview strip · Save profile button
  </section>
  <section class="card">            <!-- Links -->
    <form class="add-form"> title · URL · Add </form>
    <div class="link-list">
      <div class="link-row">         <!-- repeat per link -->
        drag · title + URL · .click-badge · up down edit delete
      </div>
    </div>
  </section>
</main>
